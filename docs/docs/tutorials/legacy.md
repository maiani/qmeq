# Legacy tutorials

These notebooks are preserved from the former QmeQ examples repository. They
contain useful advanced calculations, but they assume more background and do
not follow the step-by-step learning path of the current tutorials.

!!! warning
    Start with the numbered tutorials. They cover the material of the legacy
    notebooks — the model and its input conventions, the comparison of the
    first-order approaches, stability diagrams with excited states, the 2vN and
    RTD second-order approaches, thermoelectrics, and many-body input — with the
    validity conditions and numerical checks stated explicitly. These pages are
    kept for reference and are not maintained to the same standard.

- [Original Real Time Diagrammatics tutorial](../notebooks/legacy_tutorials/RTD_tutorial.ipynb)
